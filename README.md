# Birthday Garden Website

A mobile-first interactive birthday website recreated from the supplied Reel, with the supplied three photos and the supplied birthday-letter text.

## Files
- `index.html` — page structure and content
- `styles.css` — pastel paper/card design and animations
- `script.js` — navigation, music, album carousel, wishes and effects
- `assets/photo1.jpg`, `photo2.jpg`, `photo3.jpg` — supplied photos
- `assets/music.mp3` — audio track extracted from the supplied Reel

## Run locally
Open `index.html` in a browser. For the most reliable local preview, use VS Code Live Server.

## Host
Upload the entire folder to GitHub and enable GitHub Pages. The website is static HTML/CSS/JS, so no backend is required.
